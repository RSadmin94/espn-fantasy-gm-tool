Draft Board Monitor

Standalone dual-source board for FantasyPros Mock and ESPN Draft Room. Does not connect to Fantasy Football Rivals.

Build first: node standalone/draft-board-monitor/scripts/build.mjs then open this page from the repo (or serve the standalone/draft-board-monitor folder).

Install / launch

  1. Run the build script so dist/console-paste.js exists.
  2. Open your live draft tab:
    • FantasyPros: Mock Draft Simulator → Live
    • ESPN: existing authenticated draft room (do not open a second draft)
  3. Open DevTools → Console on that draft tab.
  4. Paste the contents of dist/console-paste.js and press Enter.
  5. Allow the popup if prompted — the board opens in a blank same-origin window.
ESPN: the monitor only reads the page DOM (Pick History). It never opens another ESPN draft connection, never clicks draft controls, and never talks to the Rivals backend.

Bookmarklet (optional)

Large bundles often exceed bookmarklet size limits. Prefer console paste. If you still want a bookmark, drag a link that loads a tiny loader you host, or paste from dist/bookmarklet.txt after build (may be truncated).

Manual validation

See MANUAL_VALIDATION.md in this folder. Do not mark PASS until both FantasyPros and ESPN live rooms are exercised.
